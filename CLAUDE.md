# Substack Author Agent — Claude Code Guide

## What this project is

Three implementations of the same Substack content strategy agent (agno / anthropic SDK / openai-agents SDK), unified behind a single FastAPI server. Originally built by Alejandro Aboy for [The Pipe and the Line](https://thepipeandtheline.substack.com) — replace the publication URL in examples with your own.

## Run the server

```bash
source .venv/bin/activate
python server.py          # starts on http://localhost:7777
```

## Run an agent via API

```bash
# Pick any agent_id: agno | claude | openai
curl -X POST http://localhost:7777/agents/agno/runs \
  -H "Content-Type: application/json" \
  -d '{"message": "...", "session_id": "optional-session-id"}'
```

### All three agents

```bash
# Agno (Claude Haiku 4.5 via Agno framework + Skills)
curl -X POST http://localhost:7777/agents/agno/runs \
  -H "Content-Type: application/json" \
  -d '{"message": "Analyze my latest articles from https://yourpublication.substack.com"}'

# Claude (Claude Haiku 4.5 via Anthropic SDK manual loop)
curl -X POST http://localhost:7777/agents/claude/runs \
  -H "Content-Type: application/json" \
  -d '{"message": "Analyze my latest articles from https://yourpublication.substack.com"}'

# OpenAI (GPT-5 Mini via OpenAI Agents SDK)
curl -X POST http://localhost:7777/agents/openai/runs \
  -H "Content-Type: application/json" \
  -d '{"message": "Analyze my latest articles from https://yourpublication.substack.com"}'
```

### Session continuity

```bash
curl -X POST http://localhost:7777/agents/claude/runs \
  -H "Content-Type: application/json" \
  -d '{"message": "What were my top articles?", "session_id": "my-session"}'

curl -X POST http://localhost:7777/agents/claude/runs \
  -H "Content-Type: application/json" \
  -d '{"message": "Generate 3 ideas based on those.", "session_id": "my-session"}'
```

### Response shape

```json
{
  "run_id": "...",
  "agent_id": "claude",
  "session_id": "my-session",
  "content": "## Article Performance\n...",
  "status": "completed"
}
```

## Run the interactive CLI

```bash
python agent.py                  # defaults to agno SDK
python agent.py --sdk claude
python agent.py --sdk openai
```

## Run the visual UI (CopilotKit + AG-UI)

Two processes:

```bash
# 1. AG-UI backend — Agno agent via AgentOS, endpoint POST /agui
source .venv/bin/activate
python agui_server.py            # http://localhost:8000

# 2. Next.js frontend with CopilotKit
cd ui && npm run dev             # http://localhost:3000
```

Features: all tool activity compressed into one collapsed "Steps" accordion per message (`ui/components/ToolCallsView.tsx`, wired via CopilotKit's `messageView.assistantMessage.toolCallsView` slot) with a live progress bar and rich reporting cards below for articles/notes/performance (recharts); raw tool data is never shown. Chart/card drilldowns send LLM follow-ups (`useSendFollowUp`). Transparent thinking (Claude extended thinking → AG-UI `REASONING_*` events), and file attachments. Visual theme cloned from substackrecapped.com via CopilotKit's native `dark` class (`cpk:dark:*` variants).

A custom `assistantMessage` slot (`ui/components/AssistantMessage.tsx`) renders the toolbar (copy / thumbs / read-aloud) and the LLM follow-up chips (`FollowUpChips.tsx`) only under the **last** assistant message once the run is idle — the agent emits several assistant messages per turn. Follow-ups are generated by the `POST /suggestions` endpoint in `agui_server.py` (a forced-tool `claude-haiku-4-5` call), proxied through `ui/app/api/suggestions/`: CopilotKit's native dynamic suggestions can't drive the Agno agent (its AG-UI router drops `run_input.tools`). Static starter prompts still use the native `before-first-message` suggestions.

> **Never run `npm run build` while `npm run dev` is serving the same `ui/` dir.** The build overwrites the live dev server's `.next` assets, so the served HTML points at CSS hashes the build replaced → 404 → unstyled page. To verify a production build, stop `next dev` first (or build in a separate checkout).

`agui_server.py` includes a "native thinking bridge": Agno streams Claude thinking deltas as `RunContentEvent.reasoning_content`, but its AG-UI translator only maps `ReasoningContentDeltaEvent` — the bridge re-tags those chunks (and closes the session with `ReasoningCompletedEvent`) so CopilotKit renders the thinking bubble. Remove it if agno fixes this upstream.

## Agent IDs and SDKs

| agent_id | SDK | Model | Observability |
|---|---|---|---|
| `agno` | Agno framework | claude-haiku-4-5 | AgnoInstrumentor → OTLP → Opik |
| `claude` | Anthropic SDK (manual loop) | claude-haiku-4-5 | track_anthropic + @opik.track |
| `openai` | OpenAI Agents SDK | gpt-5.4-nano | _CleanOpikProcessor (filters MCPListToolsSpan) |

## Key files

| File | Purpose |
|---|---|
| `server.py` | Unified FastAPI wrapper — loads all 3 agents, pre-caches SDK packages |
| `agent.py` | CLI picker (`--sdk agno\|claude\|openai`) |
| `agents/constants.py` | MCP_URL + model names |
| `agents/shared/prompt.py` | SYSTEM_PROMPT (claude + openai) + AGNO_INSTRUCTIONS |
| `agents/shared/skills.py` | Fetches skills from MCP resources (`skill://<name>/SKILL.md`) at import time |
| `agents/agno/agent.py` | Agno implementation (custom `MCPSkills` SkillLoader, extended thinking enabled) |
| `agents/claude/agent.py` | Anthropic SDK implementation |
| `agents/openai/agent.py` | OpenAI Agents SDK implementation |
| `agui_server.py` | AG-UI backend (AgentOS + AGUI interface, port 8000) + native thinking bridge |
| `ui/` | Next.js + CopilotKit v2 frontend (port 3000) — runtime route at `ui/app/api/copilotkit/` |
| `ui/components/ToolRenderers.tsx` | Generative UI: one renderer per MCP tool + wildcard fallback |

## Import trick (important)

`agents/`, `agno/`, `openai/` local folders would shadow installed packages of the same name. `server.py` and `agent.py` pre-cache the real installed packages in `sys.modules` before loading local files via `importlib`. Also adds `agents/` to `sys.path` so agent files can `from constants import ...` and `from shared.prompt import ...`.

## Environment

```
ANTHROPIC_API_KEY     — required for agno + claude
OPENAI_API_KEY        — required for openai
OTEL_EXPORTER_OTLP_*  — Opik OTLP for agno
OPIK_API_KEY          — Opik native client for claude + openai
OPIK_WORKSPACE        — Opik workspace (default: default)
```

UI (`ui/.env.local`, see `ui/.env.example`):

```
AGNO_AGUI_URL                 — AG-UI backend URL (default http://localhost:8000/agui)
NEXT_PUBLIC_PUBLICATION_URL   — your Substack URL, used in starter suggestions
```
